## Setup LexonAds (required once)

1. Open https://lexonads.com/join
2. Register / verify the GitHub Pages URL (this repo)
3. Open dashboard via NordicNodes login
4. Confirm campaign destination (can point to Linktree or this hub)

Without step 2–3, the bar may load but credits/campaign won’t attach to your account.

## Enable GitHub Pages

Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → `main` / `/ (root)` → Save.

## Local preview

Open `index.html` in a browser (ad bar needs network).
